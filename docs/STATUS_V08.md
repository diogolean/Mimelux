# Patrocino V8

This branch is a separate brand variant. `main` still shows FanMimo.

The visible product name is Patrocino in pt-BR, en, de, and fr: wordmark, page title, Open Graph image, favicon, legal copy, footer, and demo strings. The public domain shown to people is patrocino.com.

Package names (`@mimelux/*`), the database, environment variables, the `mimelux-demo` storage key, and the `MimeluxGateway` contract stay as they are. Demo accounts on `@mimelux.com.br` still sign in, as do the FanMimo aliases. `@patrocino.com` accounts (`fan@`, `criadora@`, `creator@`, `afiliado@`) map to those same roles. The password remains `mimelux123`.

The default mark is an original geometric P with a mint heart (Apoio). An alternate P with a four-point spark (Centelha) is on `/marca`. Neither copies Privacy, OnlyFans, Fanvue, or Patreon.
